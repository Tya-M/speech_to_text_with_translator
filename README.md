# 🎙️ Голосовой Переводчик

_[English version — README.en.md](README.en.md)_

Настольное приложение для **офлайн-распознавания русской речи** с переводом и
режимом **диктовки прямо под курсор** в любом приложении macOS — без облачных
сервисов распознавания и перевода.

> Обработка речи выполняется локально на Вашем компьютере. Аудио не отправляется
> в облачные сервисы. При первом запуске может потребоваться интернет для загрузки
> моделей и языкового пакета перевода.

---

## ✨ Возможности

- **Офлайн-распознавание русской речи** через **GigaAM**.
- **Перевод** распознанного текста.
- **🎤 Диктовка в курсор** — зажмите горячую клавишу, говорите, и текст
  печатается там, где стоит курсор (в браузере, редакторе, мессенджере и т.д.).
- Для диктовки можно выбрать профиль **русский** или **русский + English**.
  Русский профиль использует GigaAM, а двуязычный — Parakeet через `sherpa-onnx`
  с автоматическим использованием GigaAM для русской речи.
- **Графический интерфейс** с настройкой микрофона, чувствительности, порога VAD
  и модели распознавания.
- Настраиваемая горячая клавиша. Режим диктовки — удержание (`hold`) или
  переключение (`toggle`) — задаётся в конфигурации или через CLI.

## 🧩 Требования

- **macOS** (проверено на macOS Tahoe / macOS 26; работает и на более ранних версиях).
- **Python 3.10+**
- **ffmpeg** (нужен для GigaAM):
  ```bash
  brew install ffmpeg
  ```
- Python-зависимости перечислены в [`requirements.txt`](requirements.txt), в т.ч.:
  - `customtkinter` — графический интерфейс;
  - `pyaudio` — захват звука с микрофона;
  - `gigaam` — движок распознавания русской речи (устанавливается отдельной
    командой ниже, в `requirements.txt` он указан только в комментариях);
  - `pynput`, `pyobjc-framework-Quartz`, `pyobjc-framework-Cocoa` — печать под курсор
    и работа с горячими клавишами на macOS.

## ⚙️ Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Tya-M/speech_to_text_with_translator.git
cd speech_to_text_with_translator

# 2. Создать и активировать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установить зависимости
pip install --upgrade pip
pip install -r requirements.txt

# 4. Установить движок GigaAM (для лучшего качества)
pip install "gigaam @ git+https://github.com/salute-developers/GigaAM.git"

# 5. Опционально: установить Python-пакеты для английской диктовки Parakeet
pip install "sherpa-onnx==1.13.8" "sherpa-onnx-bin==1.13.8"
```

Для Parakeet также нужна локальная модель Unified EN. Скачайте её отдельно и
поместите файлы `tokens.txt`, `encoder.int8.onnx`, `decoder.int8.onnx` и
`joiner.int8.onnx` в каталог, указанный в `parakeet_model_path`.

При первом запуске GigaAM может скачать выбранную модель, если её ещё нет в кэше.
Argos Translate при отсутствии локального пакета скачивает индекс и языковой
пакет `ru→en`.

## 🔐 Разрешения macOS

Чтобы диктовка могла печатать под курсором и слышать микрофон, выдайте права
**тому исполняемому файлу Python, из которого запускаете приложение** (обычно это
терминал или бинарник Python в `venv`).

**Системные настройки → Конфиденциальность и безопасность →**
- **Универсальный доступ (Accessibility)** — обязательно (синтетический ввод текста);
- **Мониторинг ввода (Input Monitoring)** — обязательно (перехват горячей клавиши);
- **Микрофон (Microphone)** — обязательно (захват речи).

Узнать точный путь к бинарнику Python:
```bash
python -c "import sys, os; print(os.path.realpath(sys.executable))"
```
Добавьте именно этот файл в списки выше и **перезапустите терминал** после выдачи прав.

## 🎤 Как пользоваться диктовкой в курсор

1. Запустите приложение и дождитесь загрузки движка распознавания.
2. В панели **«🎤 Диктовка в курсор»** выберите языковой профиль и горячую клавишу
   (F7–F12, правый ⌥ или правый ⌘).
3. Нажмите кнопку диктовки — она станет красной («ВКЛ»).
4. Поставьте курсор в нужное окно, **зажмите** горячую клавишу, говорите и отпустите —
   распознанный текст напечатается в том месте, где стоит курсор.

> Диктовка запускается отдельным процессом, чтобы изолировать аудио, горячие клавиши
> и библиотеки распознавания от главного цикла GUI. Поэтому модель диктовки может
> загружаться отдельно от модели основного окна.

По умолчанию используется режим `hold`: удерживайте горячую клавишу во время речи.
Для режима переключения задайте `dictation_mode: "toggle"` в `config.json` или
запустите standalone-режим с параметром `--mode toggle`.

## 🛠️ Конфигурация (`config.json`)

Основные параметры:

| Параметр           | Назначение                                              | Пример          |
|--------------------|---------------------------------------------------------|-----------------|
| Параметр | Назначение | Пример / диапазон |
|---|---|---|
| `engine` | Основной движок распознавания; сейчас поддерживается только `gigaam` | `"gigaam"` |
| `gigaam_model` | Модель GigaAM: `v3_e2e_rnnt` или `v3_e2e_ctc` | `"v3_e2e_rnnt"` |
| `gigaam_device` | Устройство: `auto`, `cpu` или `cuda` | `"cpu"` |
| `gigaam_language` | Язык GigaAM | `"ru"` |
| `sensitivity` | Программное усиление микрофона; `1000` — без усиления | `850` (100–2000) |
| `vad_threshold` | Порог детекции речи | `700` (200–1000) |
| `device_index` | Индекс микрофона | `7` |
| `device_name` | Имя микрофона для восстановления выбора | `"fifine Microphone"` |
| `sample_rate` | Частота дискретизации, Гц | `16000` (8000–48000) |
| `chunk_duration` | Длительность аудиоокна, с | `3.0` (1.0–10.0) |
| `font_size` | Размер шрифта транскрипции | `14` (10–24) |
| `window_width` / `window_height` | Размер окна приложения | `900` / `450` |
| `translation_cache_size` | Размер кэша переводов | `100` (1–10000) |
| `partial_throttle_ms` | Интервал обновления промежуточного текста, мс | `100` (50–300) |
| `dictation_key` | Горячая клавиша: `f7`–`f12`, `alt_r` или `cmd_r` | `"cmd_r"` |
| `dictation_mode` | Режим: `hold` или `toggle` | `"hold"` |
| `dictation_engine` | Профиль диктовки: `gigaam` или `parakeet` | `"parakeet"` |
| `parakeet_model_path` | Каталог локальной модели Parakeet Unified EN | `"sherpa-onnx-nemo-parakeet-unified-en-0.6b-int8-non-streaming"` |
| `parakeet_num_threads` | Число CPU-потоков Parakeet | `2` (1–8) |

В интерфейсе изменяются модель, микрофон, чувствительность, VAD, языковой профиль
диктовки и горячая клавиша. Эти изменения сохраняются автоматически. Остальные
параметры редактируются в `config.json`; standalone CLI дополнительно позволяет
задать горячую клавишу, режим и профиль диктовки.

## ❓ Устранение неполадок

- **«Ничего не распознано» / тишина** — проверьте разрешение «Микрофон» и правильный
  индекс устройства (`device_index`); при необходимости уменьшите `vad_threshold`.
- **Текст не печатается под курсором / звуковой сигнал ошибки** — не выданы права
  «Универсальный доступ» и/или «Мониторинг ввода» нужному бинарнику Python;
  выдайте их и перезапустите терминал.
- **Ошибка при установке GigaAM** — убедитесь, что установлен `ffmpeg`.
- **Parakeet не загружается** — установите `sherpa-onnx` и `sherpa-onnx-bin`,
  затем проверьте наличие четырёх файлов модели в каталоге `parakeet_model_path`.
- **`error: externally-managed-environment`** — устанавливайте зависимости внутри
  активированного виртуального окружения (`source venv/bin/activate`).
