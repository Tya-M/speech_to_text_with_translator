# 🎙️ Голосовой Переводчик

_[English version — README.en.md](README.en.md)_

Настольное приложение для **офлайн-распознавания русской речи** с переводом и
режимом **диктовки прямо под курсор** в любом приложении macOS — без облачных
сервисов и сторонних API.

> Вся обработка речи выполняется локально на Вашем компьютере. Аудио никуда не
> отправляется.

---

## ✨ Возможности

- **Офлайн-распознавание речи** двумя движками на выбор:
  - **GigaAM** — высокое качество распознавания русского языка (рекомендуется);
  - **Vosk** — лёгкий и быстрый вариант.
- **Перевод** распознанного текста.
- **🎤 Диктовка в курсор** — зажмите горячую клавишу, говорите, и текст
  печатается там, где стоит курсор (в браузере, редакторе, мессенджере и т.д.).
- Для диктовки можно выбрать **GigaAM (русский)** или **Parakeet Unified EN
  (английский)**; Parakeet работает локально через `sherpa-onnx`.
- **Графический интерфейс** с настройкой микрофона, чувствительности, порога VAD,
  выбора движка и модели.
- Настраиваемая горячая клавиша и режим диктовки (удержание / переключение).

---

## 🧩 Требования

- **macOS** (проверено на macOS Tahoe / macOS 26; работает и на более ранних версиях).
- **Python 3.11+**
- **ffmpeg** (нужен для GigaAM):
  ```bash
  brew install ffmpeg
  ```
- Python-зависимости перечислены в [`requirements.txt`](requirements.txt), в т.ч.:
  - `customtkinter` — графический интерфейс;
  - `pyaudio` — захват звука с микрофона;
  - `vosk` — движок Vosk;
  - `pynput`, `pyobjc-framework-Quartz`, `pyobjc-framework-Cocoa` — печать под курсор
    и работа с горячими клавишами на macOS.

## ⚙️ Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Tya-M/speech_to_text_with_translator.git
cd speech_to_text_with_translator

# 2. Создать и активировать виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установить зависимости
pip install --upgrade pip
pip install -r requirements.txt

# 4. Установить движок GigaAM (для лучшего качества)
pip install "gigaam @ git+https://github.com/salute-developers/GigaAM.git"

# 5. Опционально: установить английский движок Parakeet
pip install "sherpa-onnx==1.13.8" "sherpa-onnx-bin==1.13.8"
```

> При первом запуске выбранная модель распознавания будет загружена автоматически.

## 🔐 Разрешения macOS

Чтобы диктовка могла печатать под курсором и слышать микрофон, выдайте права
**тому исполняемому файлу Python, из которого запускаете приложение** (обычно это
терминал или бинарник Python в `venv`).

**Системные настройки → Конфиденциальность и безопасность →**
- **Универсальный доступ (Accessibility)** — обязательно (синтетический ввод текста);
- **Мониторинг ввода (Input Monitoring)** — обязательно (перехват горячей клавиши);
- **Микрофон (Microphone)** — обязательно (захват речи).

Узнать точный путь к бинарнику Python:
```bash
python -c "import sys, os; print(os.path.realpath(sys.executable))"
```
Добавьте именно этот файл в списки выше и **перезапустите терминал** после выдачи прав.

## 🎤 Как пользоваться диктовкой в курсор

1. Запустите приложение и дождитесь загрузки движка распознавания.
2. В панели **«🎤 Диктовка в курсор»** выберите язык и движок.
3. Выберите горячую клавишу (F7–F12, правый ⌥ или правый ⌘) и нажмите кнопку —
   она станет красной («ВКЛ»).
4. Поставьте курсор в нужное окно, **зажмите** горячую клавишу, говорите и отпустите —
   распознанный текст напечатается в том месте, где стоит курсор.

> Модель распознавания переиспользуется приложением: при включении диктовки вторая
> копия модели в память не загружается.

## 🛠️ Конфигурация (`config.json`)

Основные параметры:

| Параметр           | Назначение                                              | Пример          |
|--------------------|---------------------------------------------------------|-----------------|
| `engine`           | Движок распознавания: `gigaam` или `vosk`               | `"gigaam"`      |
| `gigaam_model`     | Модель GigaAM                                            | `"v3_e2e_rnnt"` |
| `vad_threshold`    | Порог детекции речи (тишина/голос)                      | `700`           |
| `sample_rate`      | Частота дискретизации, Гц                                | `16000`         |
| `device_index`     | Индекс микрофона                                         | `7`             |
| `dictation_key`    | Горячая клавиша диктовки                                 | `"f9"`          |
| `dictation_mode`   | Режим: `hold` (удержание) или `toggle` (переключение)   | `"hold"`        |
| `dictation_engine` | Движок диктовки: `gigaam` или `parakeet`                 | `"gigaam"`      |
| `parakeet_model_path` | Каталог модели Parakeet Unified EN                   | `"sherpa-onnx-nemo-parakeet-unified-en-0.6b-int8-non-streaming"` |
| `parakeet_num_threads` | Число CPU-потоков Parakeet                            | `2`              |

Настройки также можно менять прямо в интерфейсе — они сохраняются автоматически.

## ❓ Устранение неполадок

- **«Ничего не распознано» / тишина** — проверьте разрешение «Микрофон» и правильный
  индекс устройства (`device_index`); при необходимости уменьшите `vad_threshold`.
- **Текст не печатается под курсором / звуковой сигнал ошибки** — не выданы права
  «Универсальный доступ» и/или «Мониторинг ввода» нужному бинарнику Python;
  выдайте их и перезапустите терминал.
- **Ошибка при установке GigaAM** — убедитесь, что установлен `ffmpeg`.
- **`error: externally-managed-environment`** — устанавливайте зависимости внутри
  активированного виртуального окружения (`source venv/bin/activate`).
